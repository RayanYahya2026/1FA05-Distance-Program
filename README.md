# Distance Calculator

## Description
This program calculates the Euclidean distance between two points on a 2D
plane, given their (x, y) coordinates. It uses Python's built-in `math`
library (`math.sqrt` and `math.pow`) to apply the distance formula:

d = sqrt( (x2 - x1)^2 + (y2 - y1)^2 )

## How to Run the Program
1. Make sure Python 3 is installed on your computer.
2. Open a terminal in the folder containing `distance_calculator.py`.
3. Run the program with:
   python distance_calculator.py
4. Follow the on-screen prompts to enter the coordinates.

## Input Needed
The program asks for four decimal (or whole) numbers, one at a time:
- x1 — x-coordinate of the first point
- y1 — y-coordinate of the first point
- x2 — x-coordinate of the second point
- y2 — y-coordinate of the second point

## Sample Output
Enter x1: 1
Enter y1: 2
Enter x2: 4
Enter y2: 6

The distance between the two points is: 5.0
